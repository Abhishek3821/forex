# forex

VTX Prime website built with React, TypeScript, React Router, Vite and Tailwind CSS.

The application lives in the `vtxPrime` directory of this repository.

## Run locally

From the repository root:

```sh
cd vtxPrime
npm install
npm run dev
```

## Checks and production build

```sh
npm run typecheck
node scripts/verify-navigation-pages.mjs
npm run build
```

The production build is written to `dist`. Configure hosting to serve `index.html` for client-side routes.

## Pages

- Platform overview, web, desktop and mobile trading, copy trading, advanced charting and trading API.
- Brokerage solutions, prop firms, liquidity providers, white label, introducing brokers and asset managers.
- Architecture, execution, risk management, FIX API, bridge, cloud infrastructure and security.
- Company information, contact and privacy policy.

Trading previews are illustrative. Contact enquiries can be prepared and opened in the visitor's email application.
